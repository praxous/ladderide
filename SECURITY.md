# Security policy

## Reporting a vulnerability

Report suspected security vulnerabilities by email to **support@praxous.dev**.

Please do **not** open a public issue for a security report.

Include what you can: affected version, platform, reproduction steps, and the impact
you believe it has. A proof of concept helps but is not required.

You will get an acknowledgement of the report. Fixes ship in a normal release, and the
release notes will credit the reporter unless anonymity is requested.

## Supported versions

Only the latest released version receives security fixes.
